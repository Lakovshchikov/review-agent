## 7.6. Режим без входа пользователя (S4U) (2026-10-02) — решение: не нужен

`register-task.ps1 ... -RunWhetherLoggedOn` с `config.change3-d.local.yaml`:
`LogonType S4U`, без окна; запуски 16:50:13 и 16:50:39 — «Нет MR,
ожидающих ревью», код 0. Значит, под S4U доступны токен `glab` и VPN.
**Вызов модели под S4U не проверен** (в конфиге `d` нет MR): авторизация
OpenCode лежит не в `auth.json` и не в `OPENAI_API_KEY` (видимо,
`~/.config/opencode/service.json` или плагин) — расшифруется ли она без
пароля пользователя, выяснит только реальный вызов. Других ревьюеров на
открытых MR нет, так что ограничить проход одним MR нельзя.

Решение пользователя: работа без входа в Windows не нужна → боевой режим —
`Interactive` (проверен полностью); в README S4U помечен как «только после
проверки настоящим ревью». Требование пользователя — пропущенный, пока он
не вошёл, проход должен выполниться после входа → задача 6.4: второй
триггер «при входе» с задержкой `-LogonDelayMinutes` (по умолчанию 5 мин,
чтобы поднялся VPN). Пробная регистрация (выключенная задача, сразу
удалена) без прав администратора: `MSFT_TaskLogonTrigger user=IVANPC\lakov
delay=PT5M` + `MSFT_TaskTimeTrigger rep=PT30M` — регистрируется.
