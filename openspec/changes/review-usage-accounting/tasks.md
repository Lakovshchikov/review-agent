  catalog(<provider>/<model>) → catalog(<model>)`, разрешение `as`,
  чтение локального файла LiteLLM (`*_cost_per_token` × 1e6),
  источник цены для вывода. Стоимость: fresh input, cache read, cache
  write, output + reasoning. Проверка — тесты: цена из конфига

  без цены дают «n/a»; число совпадает с ручным расчётом на примере из
  спеки.
- [ ] 6.2 Калибровка долей лимитов (design.md, решение 6). По каждому
  окну: валидные пары (`p2 ≥ p1`, есть ревью с ценой между
  отметками), коэффициент = ΣΔ% / Σ$, число пар. Проверка — тесты на
  сценариях спеки: 40→44 % при $8 даёт 0,5 %/$, ревью $2 даёт ≈1 %;
  пара со сбросом не учитывается; без пар доля не выводится, есть
  подсказка про `quota note`.
- [ ] 6.3 Подкоманда `review-agent usage [--since] [--until] [--by
