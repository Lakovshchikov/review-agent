- [x] 6.1 Справочник цен (design.md, решение 5): загрузка
  `price_catalog` (URL через `urllib` с таймаутом или локальный путь)
  при каждом вызове, сохранение копии в `usage/price-catalog.json`,
  запасной вариант через копию с предупреждением и датой, без копии —
  только переопределения с предупреждением. Поиск записи `overrides →
  catalog(provider/model) → catalog(model)`, переопределение целиком

  output + reasoning. Источник цены для вывода. Проверка — тесты с
  локальным HTTP-сервером или подменённым загрузчиком: свежая загрузка
  обновляет копию; сеть недоступна — используется копия и есть
  предупреждение с датой; нет ни сети, ни копии — цены только из
  переопределений и предупреждение; переопределение побеждает
  справочник; модель без цены даёт n/a; число совпадает с ручным
